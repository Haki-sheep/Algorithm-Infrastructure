# 搜索算法

```
搜索算法
├─ 无信息搜索
│  ├─ BFS
│  ├─ DFS
│  ├─ DLS
│  ├─ IDDFS
│  └─ UCS / Dijkstra
│
├─ 有信息搜索
│  ├─ GBFS
│  ├─ A*
│  ├─ IDA*
│  ├─ RBFS / SMA*
│  ├─ Weighted A*
│  ├─ Anytime A*
│  ├─ Beam Search
│  └─ 双向 A*
│
├─ 路径规划优化
│  ├─ JPS
│  ├─ Theta*
│  ├─ D* / D* Lite
│  ├─ LPA*
│  └─ HPA*
│
├─ 局部搜索与元启发式
│  ├─ Hill Climbing
│  ├─ Simulated Annealing
│  └─ Genetic Algorithm
│
└─ 对抗搜索
   ├─ Minimax
   ├─ Alpha-Beta
   ├─ Expectimax
   └─ MCTS
```
